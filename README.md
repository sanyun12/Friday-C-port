# Friday-C-port
Tentativa de fazer um port do friday night funkin 0.8.6 para console!
PARA QUE?
rodar fnf em um console do ps3 ate o ps 5, do xbox 360 ao xbox one (e o series s e x).
QUAL VERSÃO?
irei usar á 0.8.6 para esse projeto
QUE TIPO DE CONTROLE?
Preferencialmente joystick (controle de mão), mas posso adaptar para esteira de setas (arcade, kapi reference!!!)
COMO FUNCIONARA?
funcionara com semelhança á 0.8.6, mas com qualidade reduzia pra o jogo se sustentar no xbox 360 e no ps3, enquanto acima eu deixo a qualidade original.
CONTROLES?
Teclas de ação para setas (e com duas mãos o D-pad e os botões de ação)
O/A: voltar / seta right
X/B: avançar / seta down
□/X: menu / seta left
🔺️/Y: seta up

R2: caracter select
L2: space
R1: pra direita
L1: pra esquerda
Analogico R: navegação (lado baixo cima)
Analogico L: atalho indefinido
